** RetailPulse – Retail Sales Analysis Project**
                About My Project          

Hello everyone!
I have created this RetailPulse project to understand retail sales data and learn how data analytics can help a business make better decisions.

In this project, I worked with retail data to explore sales, profit, quantity sold, country-wise performance, and customer churn risk. I also created an interactive dashboard where users can select different filters and see how the results change.

My main goal was to practice data analysis and create a dashboard that presents business information in a simple and easy-to-understand way.

What I Have Done in This Project

- Analyzed retail sales data.
- Worked with cleaned data in CSV and Excel formats.
- Created KPI cards to display total sales, estimated profit, units sold, countries reached, and high churn risk.
- Created a line chart to understand monthly sales and profit trends.
- Created a bar chart to compare sales across countries.
- Added interactive filters for year, country, customer segment, churn risk, and month.
- Tested the dashboard to check whether the charts and values change when filters are selected.

Tools I Used

- HTML – to structure the dashboard
- CSS – to design the dashboard
- JavaScript – to make the dashboard interactive
- Plotly.js – to create charts
- Excel and CSV – to work with the dataset
- Jupyter Notebook – to perform data analysis

What I Learned

While working on this project, I learned how to present data using KPI cards and charts. I also learned how interactive filters help users explore data from different perspectives.

This project helped me improve my understanding of data analytics, dashboard design, and data visualization. I also learned the importance of checking data and testing a dashboard before sharing it.
